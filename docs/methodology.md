# SentimentLab AI: Methodology & Experimental Protocol

**Project:** Academic Mini-Project P4: Generative vs Discriminative Sentiment Analysis Laboratory  
**Document:** Experimental Methodology  
**Version:** 1.0  

---

## 1. Research Questions & Objective

SentimentLab AI investigates the empirical trade-offs between **discriminative machine learning models** (learning decision boundaries $P(Y|X)$) and **generative foundation models** (learning distributions $P(X, Y)$ or instruction following $P(\text{Token}_t | \text{Prompt})$) for 3-class sentiment classification (Negative, Neutral, Positive).

Key Research Questions (RQs):
1. **RQ1 (Discriminative Baseline Comparison):** How do traditional n-gram feature approaches (TF-IDF + Logistic Regression) compare in accuracy, macro-F1, and calibration to sequential representations (Keras BiLSTM) and contextualized deep representations (`bert-base-uncased`)?
2. **RQ2 (Prompting vs Fine-Tuning):** Can zero-shot and few-shot in-context learning with an instruction-tuned LLM (Google Gemini) match or outperform supervised discriminative models on domain-specific customer reviews?
3. **RQ3 (Synthetic Data Augmentation):** Does augmenting a training dataset with 500 validated synthetic reviews generated by an LLM improve out-of-sample generalization of discriminative models (Experiment B vs Experiment A), or does it introduce distribution shift / synthetic artifacts?
4. **RQ4 (Fairness & Counterfactual Sensitivity):** Do discriminative and generative sentiment models demonstrate sensitivity or bias when geographically grounded references (e.g., Pune, Mumbai, Delhi, Chennai) or demographic identifiers are interchanged under identical review semantics?

---

## 2. Experimental Conditions

To evaluate RQ3, we establish two strictly controlled conditions:

### Condition A: Real Training Baseline
- **Training Set:** 19,200 real Yelp reviews (6,400 Negative, 6,400 Neutral, 6,400 Positive).
- **Validation Set:** 4,800 real Yelp reviews (1,600 Negative, 1,600 Neutral, 1,600 Positive).
- **Evaluation Benchmark:** 3,000 fixed, stratified real evaluation samples (1,000 per class) + full 50,000 real test set for local models.

### Condition B: Real + Synthetic Augmentation
- **Training Set:** 19,200 real reviews + 500 validated synthetic reviews (167 Positive, 167 Negative, 166 Neutral) = 19,700 total training samples.
- **Validation Set:** Identical 4,800 real Yelp reviews.
- **Evaluation Benchmark:** Identical 3,000 fixed real evaluation samples.
- **Evaluation Integrity:** Synthetic reviews are **never** included in validation or test sets. All performance metrics are measured strictly on real human reviews.

## 3. Data Processing & Leakage Prevention Protocol

1. **Mapping:**
   - 1–2 stars $\to$ Class 0 (`Negative`)
   - 3 stars $\to$ Class 1 (`Neutral`)
   - 4–5 stars $\to$ Class 2 (`Positive`)
2. **Standardization Schema:**
   - `review`: Unescaped HTML, whitespace-normalized string.
   - `sentiment`: String representation (`Negative`, `Neutral`, `Positive`).
   - `label`: Integer encoding (`0`, `1`, `2`).
   - `source`: Tracking metadata (`real` vs `synthetic`).
3. **Sequestering:**
   - Test data (both full 50k and the 3,000 evaluation subset) is partitioned prior to any tokenization, TF-IDF fitting, or synthetic generation.
   - Text duplicate checking strictly prevents identical review texts across training and evaluation splits.

## 4. Evaluation Metrics & Calibration Protocol

For each model, we calculate:
- **Accuracy:** Overall correctness across the 3 classes.
- **Macro-Averaged Precision, Recall, and F1-Score:** Treating all 3 classes with equal weighting to account for any class nuances.
- **Per-Class Metrics:** F1, Precision, Recall for Negative, Neutral, and Positive.
- **Confusion Matrix:** True vs Predicted distributions highlighting inter-class confusions (e.g., Neutral misclassified as Positive).
- **Probability Calibration:**
  - Multiclass Brier Score:
    $$BS = \frac{1}{N} \sum_{i=1}^N \sum_{k=1}^K (p_{ik} - y_{ik})^2$$
  - Reliability Diagrams (plotting mean predicted probability vs true fraction of positives per probability bin).
  - Platt scaling / Isotonic regression applied via `CalibratedClassifierCV` on training/val sets only.

## 5. Academic Transparency & LLM Provider Substitution

- The academic assignment syllabus refers to GPT-based review generation.
- **Provider Substitution:** Due to open free-tier API quotas and developer accessibility, **Google Gemini** (`gemini-1.5-flash` / `gemini-2.0-flash`) is implemented via the official `google-genai` SDK.
- **Conceptual Clarification:** The Gemini API is accessed in an in-context generation and inference role. Generating 500 synthetic reviews to augment a tabular training CSV does **not** fine-tune or update the weights of the Gemini base model. The discriminative models (Logistic Regression, LSTM, BERT) are the ones retrained in Condition B.
